Step 1 & 2 • Forward Model & Single-Pass Spline Continuum Normalization

Synthetic High-Resolution Planetary Transmission Spectrum (R = 100,000)

42 Resolved Ro-Vibrational Lines

Methodology note: In the pipeline developed at INAF Catania, synthetic planetary absorption lines from petitRADTRANS are injected into blaze-modulated stellar echelle spectra. Fitting a single-pass cubic spline (scipy.interpolate.UnivariateSpline) directly to the blaze-uncorrected order removes both the stellar continuum and the parabolic echelle blaze function simultaneously.

Step 3 • 2D CCF Velocity Matrix

Orbital Phase (φ) vs. Radial Velocity

Hover matrix

Each row cross-correlates one transit phase (φ ∈ [-0.045, +0.045]) against the planetary template over RV ∈ [-250, +250] km/s. The slanted bright ridge traces the planet’s orbital acceleration v_p(φ).

Step 4 • Rest-Frame Alignment

Co-Added CCF vs. Selected Phase Slice

RV Grid: ±250 km/s

Shifting each row of the 2D CCF matrix into the planet’s rest frame using the trial (K_p, V_sys) and co-adding yields the sharp cyan detection peak at V_sys = -15 km/s (amber curve shows single phase φ = +0.000).
